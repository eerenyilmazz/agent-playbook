# Sprint Cadence

## Default rhythm (1-week or 2-week sprints)
- **Planning (start):** Pick work by priority and capacity. Each item has acceptance criteria and an owner.
- **Daily check-in:** What's done, what's next, what's blocked. Blockers are acted on the same day.
- **Review (end):** Demo what's done against acceptance criteria. Only "done" items count.
- **Retro (end):** One thing to keep, one to change, with an owner.

## Rules
- Plan to about 80% of capacity; the rest absorbs bugs and surprises.
- Scope changes mid-sprint are swaps, not additions.
- Unfinished work returns to the backlog and is re-estimated; no silent carry-over.
- The definition of done is in company/engineering-principles.md.

## Reporting
At sprint end, a short update: done, not done (why), risks, next sprint focus.
