# Sprint Cadence

## Rhythm (1–2 weeks)
- **Planning:** pick ready items by priority; load to ~80% capacity.
- **Daily:** done / next / blocked. Blockers handled the same day.
- **Review:** demo against acceptance criteria; only done counts.
- **Retro:** one keep, one change, with owner.

## Rules
- Mid-sprint scope changes are swaps, not additions.
- Unfinished items return to backlog and are re-estimated.
- Done = company/engineering-principles.md.

## Report (end of sprint, ≤ 10 lines)
Done · not done + why · risks · decisions needed · next focus. Track velocity and carry-over trend.
