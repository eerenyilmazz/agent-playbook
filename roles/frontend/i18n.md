# Internationalization

## Rules
- No hard-coded UI text; namespaced keys (`checkout.payment.cardDeclined`).
- Placeholders, never concatenated fragments. ICU plural/select rules.
- Locale-aware formatting for dates, numbers, currency. Store UTC; display in user time zone.
- Layouts tolerate ~40% longer text. RTL planned early if needed.
- `lang` reflects current language. Language choice persisted.
- Translation files lazy-loaded per language.
- Missing key fails CI or logs clearly; raw keys never shown in prod.

## Turkish
- Locale-aware case: `toLocale(Upper|Lower)Case('tr')` (i/İ, ı/I).
- Locale-aware sorting (`Intl.Collator('tr')`).
